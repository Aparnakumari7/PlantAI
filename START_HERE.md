## The Simplest Path (Copy-Paste)

### Step 1: Open This Link in Your Browser

```
https://render.com/deploy?repo=https://github.com/Aparnakumari7/PlantAI
```

**OR go to Render and click:**
1. Dashboard → **New +** → **Blueprint**
2. Paste: `https://github.com/Aparnakumari7/PlantAI`

### Step 2: Render Will Show You a Form

Just fill in:
- **Service Name**: `drplant-ai-backend` (default is fine)
- **Database Name**: `drplant-db` (default is fine)
- **JWT_SECRET**: Generate one at https://generate-secret.vercel.app/

Copy the 4 fields Render shows you and click **Deploy**

### Step 3: Wait 3-5 Minutes

Render will:
- Create PostgreSQL database
- Build your backend
- Deploy it
- Show "Live" when done

### Step 4: Tell Me Your Backend URL

Once deployed, Render will show:
```
https://drplant-ai-backend.onrender.com
```

**Come back and tell me this URL**, and I'll:
- Update your frontend
- Connect everything
- Deploy to Vercel
- Done! 🎉
