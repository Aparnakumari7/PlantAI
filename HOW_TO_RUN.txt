================================================================================
                    PLANT DISEASE DETECTOR - SETUP GUIDE
================================================================================

PROJECT OVERVIEW:
-----------------
A full-stack AI-powered plant disease detection application using:
- Frontend: React 19 + Vite
- Backend: Node.js + Express
- Database: SQLite3
- AI: Google Gemini API (gemini-2.5-flash-lite)
- Voice: Web Speech API (English Language)

================================================================================
                          INSTALLATION & SETUP
================================================================================

STEP 1: INSTALL DEPENDENCIES
-----------------------------
Open terminal in the project folder and run:

    npm install

This will install all required packages from package.json.


STEP 2: VERIFY ENVIRONMENT VARIABLES
-------------------------------------
Check the .env file in the root directory:

    VITE_GEMINI_API_KEY=AIzaSyDAWzX2ypGSSp7bnCBSlVPqttJn1YYGXhs

If you need a new API key:
1. Go to: https://aistudio.google.com/app/apikey
2. Create a new API key
3. Replace the value in .env file


STEP 3: RUN THE PROJECT
------------------------
There are two ways to run the project:

METHOD 1 - Run Both Servers Together (RECOMMENDED):
    npm run dev:full

This starts:
- Frontend (Vite) on: http://localhost:5173/
- Backend (Express) on: http://localhost:5000/


METHOD 2 - Run Servers Separately:
Open TWO terminal windows:

Terminal 1 (Backend):
    node backend/server.js

Terminal 2 (Frontend):
    npm run dev


STEP 4: ACCESS THE APPLICATION
-------------------------------
Open your browser and go to:
    http://localhost:5173/


STEP 5: BROWSER COMPATIBILITY (IMPORTANT)
-----------------------------------------
For the Voice-to-Voice features (STT/TTS) to work optimally:
- USE: Google Chrome or Microsoft Edge (Latest versions)
- Safari/Firefox have limited support for SpeechRecognition.
- Ensure your microphone is enabled in browser settings.

================================================================================
                          SQLITE DATABASE COMMANDS
================================================================================

DATABASE LOCATION:
------------------
    backend/database.sqlite


HOW TO ACCESS SQLITE DATABASE:
-------------------------------

Option 1 - Using SQLite Command Line:
1. Install SQLite: https://www.sqlite.org/download.html
2. Open terminal in project folder
3. Run: sqlite3 backend/database.sqlite


Option 2 - Using DB Browser for SQLite (GUI):
1. Download from: https://sqlitebrowser.org/
2. Open the file: backend/database.sqlite


USEFUL SQL COMMANDS:
--------------------

1. VIEW ALL TABLES:
   .tables

2. VIEW TABLE STRUCTURE:
   .schema users
   .schema predictions

3. VIEW ALL USERS:
   SELECT * FROM users;

4. VIEW ALL PREDICTIONS/SCANS:
   SELECT * FROM predictions;

5. COUNT TOTAL USERS:
   SELECT COUNT(*) as total_users FROM users;

6. COUNT TOTAL SCANS:
   SELECT COUNT(*) as total_scans FROM predictions;

7. COUNT HEALTHY VS DISEASED PLANTS:
   SELECT 
     SUM(CASE WHEN is_healthy = 1 THEN 1 ELSE 0 END) as healthy,
     SUM(CASE WHEN is_healthy = 0 THEN 1 ELSE 0 END) as diseased
   FROM predictions;

8. VIEW USER'S SCAN HISTORY:
   SELECT * FROM predictions WHERE user_id = 1;

9. VIEW RECENT SCANS (Last 10):
   SELECT p.*, u.username, u.email 
   FROM predictions p 
   JOIN users u ON p.user_id = u.id 
   ORDER BY p.timestamp DESC 
   LIMIT 10;

10. FIND SPECIFIC DISEASE:
    SELECT * FROM predictions 
    WHERE disease_name LIKE '%blight%';

11. DELETE A SPECIFIC SCAN:
    DELETE FROM predictions WHERE id = 1;

12. DELETE ALL SCANS FOR A USER:
    DELETE FROM predictions WHERE user_id = 1;

13. DELETE A USER (and their scans):
    DELETE FROM predictions WHERE user_id = 1;
    DELETE FROM users WHERE id = 1;

14. MAKE A USER ADMIN:
    UPDATE users SET is_admin = 1 WHERE username = 'admin';

15. VIEW ADMIN USERS ONLY:
    SELECT * FROM users WHERE is_admin = 1;

16. COUNT SCANS PER USER:
    SELECT u.username, COUNT(p.id) as scan_count
    FROM users u
    LEFT JOIN predictions p ON u.id = p.user_id
    GROUP BY u.id
    ORDER BY scan_count DESC;

17. MOST COMMON DISEASES:
    SELECT disease_name, COUNT(*) as count
    FROM predictions
    WHERE is_healthy = 0
    GROUP BY disease_name
    ORDER BY count DESC
    LIMIT 10;

18. CLEAR ALL DATA (RESET DATABASE):
    DELETE FROM predictions;
    DELETE FROM users;

19. BACKUP DATABASE:
    .backup 'backup_database.sqlite'

20. RESTORE DATABASE:
    .restore 'backup_database.sqlite'


DATABASE SCHEMA:
----------------

USERS TABLE:
------------
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT UNIQUE NOT NULL,
  email TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,
  is_admin BOOLEAN DEFAULT 0,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

PREDICTIONS TABLE:
------------------
CREATE TABLE predictions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  plant_name TEXT,
  is_healthy BOOLEAN,
  plant_confidence REAL,
  disease_name TEXT,
  treatment TEXT,
  image_path TEXT,
  timestamp DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users (id)
);


================================================================================
                          TROUBLESHOOTING
================================================================================

PROBLEM: "Port 5000 already in use"
SOLUTION: 
    - Kill the process using port 5000
    - Windows: netstat -ano | findstr :5000
              taskkill /PID <PID> /F
    - Or change port in backend/server.js

PROBLEM: "API key not working"
SOLUTION:
    - Get new key from: https://aistudio.google.com/app/apikey
    - Update .env file
    - Restart the servers

PROBLEM: "Database locked"
SOLUTION:
    - Close all SQLite connections
    - Restart the backend server

PROBLEM: "Module not found"
SOLUTION:
    - Delete node_modules folder
    - Delete package-lock.json
    - Run: npm install

PROBLEM: "AI service overloaded"
SOLUTION:
    - Wait 10 seconds and try again
    - The app has automatic retry logic with 5 attempts
    - Using stable gemini-2.5-flash-lite model for reliability

PROBLEM: "Voice/Mic not working"
SOLUTION:
    - Check if you are using Google Chrome or Edge.
    - Click the 'Lock' icon in the URL bar and ensure Microphone access is "Allow".
    - Check if the page is served over HTTPS (or localhost).
